# 🧩 src/components/ — UI Components

This directory contains reusable React 19 UI components.

## 📁 Key Components
- `Header.tsx`: Navigation bar with mega menu, search, size filter bar, and language switcher.
- `Hero.tsx`: Main architectural hero stage with interactive tile preview card.
- `ProductCard.tsx`: Product item card with hover zoom, face count badge, and quote trigger.
- `ProductDetailModal.tsx`: Product detail view with lightbox zoom, face variation switcher, ISO specs table, and PDF download.
- `FilterSidebar.tsx`: Advanced catalog filters by size, finish, body type, and collection.
- `CompareModal.tsx`: Side-by-side comparison table for up to 4 tiles.
- `InquiryBasketModal.tsx`: Price quote request basket drawer.
- `RoomVisualizer.tsx`: Online tile chitan simulator for living room, bathroom, lobby, and facade.
- `WhatsAppButton.tsx`: Floating WhatsApp chat button with pre-filled product context.
- `SeoSchema.tsx`: Injects JSON-LD structured data for Google SEO.
- `admin/`: Admin Panel dashboard, 2FA auth, inline sheet editor, and CMS modal editors.
